# 商品库工具 v2.2

商品库语义清洗去重 + 新品查重 + 销售订单匹配，集成 DeepSeek AI 复核。

## 功能

| 模块 | 功能 | 说明 |
|------|------|------|
| **清洗去重** | 上传商品库 → 自动清洗 → DeepSeek 复核 → 导出 | 完全重复/抄码名重复/异名同物/缺省值 |
| **新品查重** | 上传商品库建索引 → 上传接龙表 → 逐条查重 | 规则找候选 + DeepSeek 判断 |
| **订单匹配** | 上传销售订单 → 自动统计编码引用次数 → 判定保留/下架 | 支持客户/商户/食堂列识别 |

## 快速开始

1. 下载 `dist/商品库工具_v2.2_安装包.exe`
2. 双击安装（自动检测旧版本升级）
3. 首次使用点右上角 ⚙设置 → 填入 DeepSeek API Key → 保存

## 文件结构

```
├── web/              # Flask 应用
├── scripts/          # 规则引擎 + 翻译器 + DeepSeek 判断
├── docs/             # 设计文档（按阶段）
├── data/             # 测试数据
├── dist/             # exe + 安装包
└── 商品库工具.spec    # PyInstaller 配置
```

## 技术栈

Python + Flask + openpyxl + DeepSeek API + PyInstaller + Inno Setup
