# PRD：三期 — 工具封装与交付

## 问题陈述

二期引擎已能用，但只有开发机能跑。需要封装为双击即用的工具交付给同事。

## 目标用户

采购/运营同事。不会命令行，不装 Python。Windows 电脑使用。

---

## 功能需求

### P0（必须有）

- **FR-001：双击启动** — 一个 exe，双击自动打开浏览器
- **FR-002：上传查重** — 上传接龙表 → 逐行 DeepSeek 判断 → 实时进度和结果
- **FR-003：结果导出** — 导出为 Excel：建议复用时写入原表"系统编码"列(col12)，所有结果追加"匹配结果"(col13)+"匹配详情"(col14)两列
- **FR-004：API Key 配置** — 界面上填写 DeepSeek API Key
- **FR-005：首次使用引导** — API Key 未填时提示用户先配置，接龙表格式不对时提示正确列结构

### P1（应该有）

- **FR-101：任务控制** — 开始、暂停、停止、重置
- **FR-102：结果筛选** — 按"建议复用""需新增""待确认"筛选
- **FR-103：配置外置** — 品牌/异名/加工前缀在 Excel 中维护（DeepSeek 已覆盖大部分场景，此需求降低优先级）

### P2（锦上添花）

- **FR-201：历史记录** — 保存查重历史
- **FR-202：模型选择** — 切换 DeepSeek 模型
- **FR-203：基准库更新** — 新增商品后可重建索引并更新 exe

---

## 技术方案

| 层 | 选型 | 理由 |
|----|------|------|
| 后端 | Python Flask | 与二期同语言 |
| 前端 | HTML + JS | 无需构建工具 |
| 打包 | PyInstaller | Python → exe |
| 配置 | Excel | 用户最熟悉 |

### 数据流

```
接龙表.xlsx → Web 上传 → Flask
                          ├── 第一步: 规则引擎(翻译+候选)
                          └── 第二步: DeepSeek(判断) → 结果 → 导出
```

### 文件结构

```
scripts/        # 二期引擎（已有）
web/app.py      # Flask 后端
web/templates/  # HTML 前端
index.json      # 基准库
配置.xlsx        # 可维护配置
```

---

## 范围

**在范围内：** Flask + HTML 前端 + 上传/查重/导出 + 配置 Excel + PyInstaller exe

**不在范围内：** ERP 对接、多用户、云端部署、模型本地化

## 风险

| 风险 | 缓解 |
|------|------|
| exe 体积大（~100MB） | index.json 3.5MB + Python 运行时 60MB，可接受 |
| API 调用慢（2秒/条） | 异步处理，实时进度 |
| 端口冲突 | 可配置端口 |

## 成功标准

- [ ] 双击 exe 启动，浏览器自动打开
- [ ] 上传接龙表 → 显示结果 → 导出 Excel
- [ ] 配置 Excel 修改后无需重启
- [ ] 无 Python 电脑可运行

## 验收方式

1. 开发机启动 Web 服务，上传接龙表测试
2. 打包 exe 后同事电脑测试
3. 修改配置 Excel，验证新配置生效
