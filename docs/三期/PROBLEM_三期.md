# 问题陈述：三期 — 工具封装与交付

## 问题

二期查重引擎已能正确工作。但只能在开发电脑上用命令行运行，无法交付给实际使用者（采购/运营同事）。

同事不会装Python、不会配环境变量、不会开命令行。需要做成双击即用的工具。

## 背景

- 二期已完成：translator + matcher + judge + build_index，10/10验收通过
- 一期已完成：12440条基准库清洗去重
- DeepSeek API Key 需自行注册（platform.deepseek.com，几块钱起充），在界面上配置
- 基准库 index.json 随版本发布，新增商品后需重建索引并更新 exe
- 约束：Windows，Python + openpyxl，不依赖外部 API 以外的网络

## 目标

同事拿到一个文件，双击就能用。上传接龙表，出查重结果。不需要装任何东西。

## 成功标准

- [ ] 双击 exe 启动，浏览器自动打开 Web 界面
- [ ] 上传接龙表 → 逐行查重 → 显示结果 → 导出结果 Excel
- [ ] 加工前缀等少量引擎配置可在 Excel 中维护（品牌/异名 DeepSeek 已能自行判断）
- [ ] 在未装 Python 的 Windows 电脑上可运行

## 不在范围内

- ERP 系统对接（四期）
- 多用户/权限管理
- 云端部署
- AI 模型本地化
