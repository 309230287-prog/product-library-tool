# 问题陈述：六期 — 销售订单匹配

## 问题

清洗去重后重复组的建议是"与XXX名称单位分类相同，保留其一"，没有给出**保留哪一个、下架哪一个**的行动指南。

实际业务中需要：同组内比对各编码的销售订单引用次数，次数高的保留，次数低的下架。附带客户名称，方便向客户解释"为什么这个编码要下架"。

一期手动导出销售订单 → Excel 里手工匹配 → 填 `重复编码下架保留清单.xlsx`。这个过程没有集成到工具里。

## 参考输出

`重复编码下架保留清单.xlsx`，共 13 列，分 3 个 Sheet：

| Sheet | 内容 |
|-------|------|
| Sheet1 | 完全重复 + 异名同物 |
| Sheet2 | 正常（无异常但有订单数据） |
| Sheet3 | 抄码名重复 |

新增 4 列（原 9 列之外）：

| 列 | 含义 | 示例 |
|----|------|------|
| 是否下架/保留 | 订单数高的→"保留"，低的→"下架"，无数据→空 | 保留 |
| 替代编码 | 组内对方 SPUID 交叉引用 | C34345634 |
| 订单命中次数 | 该 SPUID 在销售订单中出现的行数 | 42 |
| 订单命中客户 | 去重后的客户名称，换行分隔 | 单54(光明围台)\n单158(海警21540艇) |

判定规则：

```
同组内比较订单命中次数：
  次数高 → 保留 → 替代编码填对方的 SPUID
  次数低 → 下架 → 替代编码填对方的 SPUID
  次数相同 → 都不填
  无数据 → 两个都空
```

## 背景

- 一期手动做过：导出销售订单 → Excel 里 VLOOKUP → 手工填保留/下架
- 四期模块A 已实现完整清洗+复核流程
- 订单文件格式与一期导出一致，后期可能来自不同系统
- 订单上传选填——不传也能正常清洗

## 目标

模块A 清洗完成后，可选上传销售订单，自动匹配 SPUID+客户，按命中次数判定保留/下架，结果 13 列，导出 3 Sheet。

## 成功标准

- [ ] 清洗完成后出现选填上传区"上传销售订单（可选）"
- [ ] 自动识别订单文件的 SPUID 列 + 客户/商户名列
- [ ] 结果表格 13 列（原 9 列 + 是否下架/保留 + 替代编码 + 订单命中次数 + 订单命中客户）
- [ ] 同组内次数高→保留、低→下架、次数相同→按原规则
- [ ] 导出 Excel 分 3 个 Sheet
- [ ] 不上传订单 → 清洗正常，后 4 列为空
