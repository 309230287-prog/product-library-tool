# 商品库整理项目

## 核心思想

**这不是字符串处理任务，是语义翻译任务。**

SPU名称、单位、描述、分类四个字段是一段话，告诉你"这是个什么东西、怎么卖的"。
你要做的不是匹配字符串，是理解这段话的意思，然后把意思相同的东西找出来。

```
"冬枣抄码-AA450582 / 斤 / 抄码 / 水果类"
    ↓ 翻译
冬枣，称重卖，老编码AA450582（忽略），水果类

"冬枣 / 斤 / (空) / 水果类"
    ↓ 翻译
冬枣，没有写规格，水果类

→ 意思相同，就是同一个东西的两种写法
```

```
"1*6瓶" → 1份，每份6瓶，总共6瓶
"6瓶*1" → 6瓶，1份
→ 意思相同
```

```
"兰花一品鲜 / 瓶 / 1.65L / 干调类"
"兰花一品鲜 / 瓶 / 500ml / 干调类"
→ 容量不同，不同SKU，不是同一个东西
```

## 四个字段的语义角色

| 字段 | 说的是什么 |
|------|-----------|
| SPU名称 | 这是什么东西（可能混了品牌、方言名、老编码后缀） |
| SPU基本单位 | 怎么卖（斤≠包≠件，单位不同就是不同卖法） |
| SPU描述 | 什么规格（重量、容量、数量、包装方式，空和抄码都是"没写"） |
| 一级分类 | 属于哪一类 |

## 老编码后缀

名称末尾的 `-AA数字`、`-BB数字` 之类是老编码体系残留，**在理解商品名时忽略**。它们不是商品名的一部分。

## 抄码

"抄码" = 称重售卖。是一个规格描述，不是商品名的组成部分。理解商品名时如果遇到"抄码"要跳过。

## 必须抛弃的做法

- ❌ 字符串比对其是否相等
- ❌ 关键字/子串匹配
- ❌ 正则当业务逻辑

## 必须坚持的做法

- ✅ 先翻译每个字段的意思，再比较意思是否相同
- ✅ 名称、单位、描述、分类四个字段一起看
- ✅ 硬编码已知等价关系（异名表）
- ✅ 单位不同即不同商品
- ✅ 分类是重要的过滤条件

## 技术约束

- Python + openpyxl
- 禁止调用外部API
- 12440行锁定，不能多不能少
- 列数/Sheet数不变
- 每行只属于一个异常分类

## 工作方式

- 小步修改，每步一个明确问题
- 改前先读文件
- 输出中文说明
- 每次修改后说明改了什么、为什么
