# 主流程

## 功能

读取新品新增接龙表，对无系统编码的行进行四维匹配，反写系统名称和编码。

## 输入

`新品新增接龙表.xlsx`，工作表1：

| 列 | 字段 | 匹配用途 |
|----|------|---------|
| 2 | *品牌 | 品牌维度（None/"无要求"=无品牌） |
| 3 | *名称 | 品名维度 |
| 4 | *规格 | 规格维度（等同于描述） |
| 5 | *类别 | 辅助（状态冗余判断） |
| 6 | *单位 | 单位维度 |

## 输出

同一文件，反写有数据的列：
- 第10列 系统名称 → 匹配到的基准库商品名
- 第11列 系统编码 → 匹配到的SPUID

## 流程

```
1. 加载 index.json
2. 读取新品新增接龙表.xlsx
3. 筛选：第11列(系统编码)为空的行
4. 逐行:
   a. 组装输入: name=*名称, brand=*品牌, desc=*规格, unit=*单位, category=*类别
   b. 翻译新品 → TranslatedItem + SpecResult
   c. check_one(item, index) → MatchResult
   d. 如 result="建议复用":
      - 反写 系统名称 = 匹配项raw_name
      - 反写 系统编码 = suggested_spuid
   e. 如 result="需新增" 或 "待确认":
      - 留空（人工决定）
5. 保存
```

## 处理范围

只处理第11列(系统编码)为空的行（当前62条/660行），已有编码的598行跳过。

## 注意

- 无单独的备注列——加工意图检测可能不触发（除非规格列含加工描述）
- 品牌列"无要求"视为无品牌
- 规格列内容自由文本，可能含尺寸、包装、品质描述
